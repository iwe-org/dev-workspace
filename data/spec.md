# 📐 Spec

*Behavioral specifications — the durable truth about how the product must work,
one topic per document in `spec/<slug>.md`. Specs carry no frontmatter; they are
reference material, not work items. Write requirements as `### Requirement:`
sections with SHALL statements and `#### Scenario:` WHEN/THEN examples. The ship
skill updates affected specs whenever a plan ships, so this section never drifts
from the code.*
