# Plan the first feature

Pick the next thing you intend to build and run the plan skill
(`.claude/skills/plan/`): it files `data/plans/YYYYMMDD-<slug>.md` with verified
code anchors, names the specs the work will touch, and lists the plan under
Active. The first plan is how the workspace's loop — plan, implement, ship —
starts turning.
