# Import the existing backlog

Wherever your pending work currently lives — issue tracker, TODO comments, a
notes file, your head — move it into the graph: one `data/backlog/<slug>.md`
task per item with a priority, or a `data/someday/` note for ideas that aren't
commitments. The workspace can only sequence work it can see.
